# ☔ 비쏙맵 BissokMap · ビッソクマップ (인천·부천·김포·서울 실내 나들이)

비 오는 날 아이와 갈 만한 **실내** 명소를 지도·필터로 찾는 정적 웹앱입니다.
한국어/일본어를 즉시 전환할 수 있고, 모든 장소는 공식 홈페이지·공공데이터로 확인한 정보만 실었습니다.
2단계에서 **총 68곳**(기존 31 + 서울 37)으로 늘리고, 화면 전체를 **웜 그레이지 · 코코아 브라운** 톤으로 바꿨습니다.
5단계에서 아이가 실제로 뛰어노는 **놀거리·체험 18곳**을 더해 **총 86곳**이 되었고, **테마(유형) 필터**로 박물관을 빼고 액티비티·동물·체험만 골라볼 수 있습니다.
3단계에서 지도를 OpenStreetMap(Leaflet) 단독에서 **카카오맵 JavaScript SDK + 클러스터러 기본, OSM Leaflet 자동 폴백**으로 전환했습니다.
4단계에서 **찜하기(즐겨찾기)** 와 **장소 링크 공유(`?place=` 딥링크)** 를 추가했습니다.

## 실행

- 라이브: **https://bissokmap.github.io/** (GitHub Pages, `bissokmap/bissokmap.github.io` `main` 브랜치 루트 게시)
- 이전 주소: `https://inje8451.github.io/Rainy-kids-map/` (구 저장소, 새 주소로 통합)
- 앱 이름: 한국어 **비쏙맵**, 일본어 **ビッソクマップ (BissokMap)**
- `index.html`을 브라우저로 열면 바로 동작합니다(빌드·서버 불필요).
- GitHub Pages 등 아무 정적 호스팅에 폴더째 올려도 됩니다.
- 지도는 **카카오맵 JavaScript SDK**(클러스터러 포함)가 기본입니다. 키는 `5319f5b0184334165a52b3413de7b6d8`이며 카카오 디벨로퍼스에 `https://inje8451.github.io` 도메인이 등록돼 있습니다. **`https://bissokmap.github.io` 도메인은 아직 카카오에 등록 전이라, 등록하기 전까지 새 주소에서는 SDK 타일이 오지 않고 아래 Leaflet+OSM 폴백으로 표시됩니다.** (카카오 디벨로퍼스 → 내 애플리케이션 → 플랫폼 → Web 사이트 도메인에 `https://bissokmap.github.io` 추가 필요)
- 카카오 SDK를 못 불러오거나(스크립트 차단·오프라인) 등록되지 않은 도메인에서 타일이 오지 않으면 **Leaflet + OpenStreetMap으로 자동 폴백**합니다(웜 그레이지 필터 + 실패 시 OSM France 자동 전환). 지도가 빈 화면이 되지 않습니다.

```
work/rainy-kids-map/
├─ index.html
├─ assets/styles.css        # 웜 그레이지 · 코코아 브라운 팔레트, 모바일 퍼스트 + 데스크톱 분할
├─ assets/app.js            # 필터·지도(카카오맵/Leaflet 폴백)·모달·한/일 전환
├─ data/places.js           # ★ 데이터 원본 (window.RKM_PLACES)
├─ data/places.json         # 같은 데이터의 JSON 사본
├─ build/                   # 데이터 생성 스크립트 (seoul_a.py · seoul_b.py → build.py)
├─ vendor/leaflet/          # Leaflet 1.9.4 로컬 사본 (폴백용)
├─ shots/                   # 검증 스크린샷 (지도 엔진 전환 후)
├─ verify.py                # Playwright 검증 스크립트 (카카오맵 + 폴백)
├─ verify-fav.py            # 4단계 검증 (찜하기 · ?place= 딥링크 · 링크 복사/공유)
├─ verify-theme.py          # 5단계 검증 (테마 필터 · 신규 18곳)
└─ verify-report.json       # 검증 결과 원본
```

데이터를 고칠 때는 `build/seoul_a.py`·`seoul_b.py`(서울)와 기존 `data/places.json`(인천·부천·김포)을 수정한 뒤
`python3 build/build.py`를 실행하면 `places.json`과 `places.js`가 함께 갱신됩니다.

## 4단계 · 찜하기 & 장소 링크 공유 (2026-11-26)

- **찜하기**: 목록 카드 오른쪽 위와 상세 모달에 `♡ / ♥` 버튼. 누르면 `localStorage`의 `rkm.favs`(id 배열, 최근 담은 순)에 저장돼 새로고침·재방문 후에도 유지됩니다. 카드를 눌러 상세를 열 때와 헷갈리지 않게 하트 버튼은 클릭 이벤트를 따로 받습니다.
- **찜한 곳 모아보기**: 검색창 아래 `♡ 찜한 곳 N` 칩을 누르면 찜한 장소만 남고, 지도 마커·클러스터도 같은 목록으로 다시 그려집니다(개수 배지 표시, JP는 `お気に入り`). 찜이 없으면 "찜한 곳이 없어요 / 목록 카드나 상세 화면의 ♡를 눌러 담아 두면 여기에 모여요." 안내를 보여 줍니다. `초기화`는 찜 필터도 함께 풀립니다.
- **장소 링크 공유**: 상세 모달의 `🔗 링크 복사`(JP `リンクをコピー`)가 `https://bissokmap.github.io/?place={장소 id}` 형식 주소를 복사하고 "링크를 복사했어요" 토스트를 띄웁니다. 클립보드 API를 못 쓰는 환경은 textarea+execCommand로 복사합니다. `navigator.share`를 지원하는 기기(iOS·안드로이드 브라우저)에서는 `공유` 버튼이 함께 나와 기기 공유 시트로 이름·한 줄 소개·주소를 넘깁니다. 일본어로 보는 중이면 주소에 `&lang=ja`가 붙어 받는 사람도 같은 언어로 열립니다.
- **딥링크**: `?place={id}`(+`&lang=ja`)로 접속하면 그 장소의 상세 모달이 자동으로 열리고 지도도 그 위치로 이동합니다. 모바일에서 지도 탭을 나중에 열어도 그 장소로 이동하며, 없는 id는 무시하고 평소 목록을 보여 줍니다.
- 색은 기존 팔레트 그대로입니다 — 찜 하트는 테라코타 `#a8432c`, 활성 칩은 코코아 `#8a6247`, 토스트는 코코아 블랙.
